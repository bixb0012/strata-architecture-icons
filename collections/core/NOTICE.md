The icons fall into three groups by source:

| Source | Icons | Description in each file |
| --- | --- | --- |

| New, with parts redrawn from Esri's toolkit (the server rack, the cylinder or the line globe) | Server, Virtual Machine, Web Server, API Gateway, VPN Gateway, Database, Cache, Backup, Internet | "Strata architecture icons, core collection. | New | Container, Container Cluster, Message Queue, Workstation, Router, Switch | "Strata architecture icons, core collection. Licensed CC BY 4.0." |

`manifest.json` records the source of every icon (`source`).

**Changes from Esri's originals.** The icons adapted from Esri's toolkit are the same drawings as in Strata's ArcGIS collection. The changes from Esri's originals are listed in that collection's [NOTICE.md](../arcgis/NOTICE.md#changes-from-the-original). In short, they are redrawn as filled, layered shapes in the Fluorite palette, with light and dark versions and SVG and PNG files. The Visio stencils use Esri's stencil packages, with each shape's artwork replaced. They keep Esri's shape names and connection points.
